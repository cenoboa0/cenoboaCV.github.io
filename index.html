CASO 01 — WEB / CTF

          
Warzone VIU: CTF de Aplicaciones Web

          
Investigador de Seguridad / Pentester — Máster en Ciberseguridad, VIU

        

        
+

      

      

        

          
Escenario

          
Evaluación de seguridad completa sobre la plataforma de entrenamiento CTF de la Universidad Internacional de Valencia, compuesta por 9 laboratorios independientes que simulan vectores de ataque reales en aplicaciones web del dominio viuciberseguridad.wsg127.com.

          
Logros

          
Resolución del 100% de los laboratorios asignados con captura de todas las banderas disponibles: explotación de XSS mediante evasión de filtros (JSFuck, codificación hexadecimal/HTML, nested payloads); elusión de autenticación vía manipulación de tipos de dato PHP y deserialización insegura de cookies en Base64; exfiltración automatizada de credenciales mediante Boolean-Based Blind SQL Injection con script Python a medida; y obtención de credenciales por diccionario con THC Hydra sobre un formulario sin rate limiting.

          
Metodología

          
Reconocimiento → análisis de código fuente → construcción de payload → explotación → documentación de evidencias, con trazabilidad mediante interceptación de tráfico HTTP en Burp Suite Repeater.

          

            Kali Linux
            Burp Suite
            Python (requests)
            THC Hydra
            Firefox DevTools

Investigador de Seguridad / Pentester

Escenario

          
Fase de reconocimiento pasivo y modelado de amenazas sobre la infraestructura digital de una organización de comercio electrónico, buscando identificar vectores de exposición sin generar alertas en los sistemas defensivos.

CASO 03 — R / ANALÍTICA

          
Minería de Datos y Automatización en R: Incidentes SSH

          
Investigador de Seguridad / Científico de Datos de Red

        

        
+

      

      

        

          
Escenario

          
Automatización de un entorno de trabajo reproducible en RStudio para la ingesta, manipulación y análisis estadístico exploratorio masivo de registros de acceso SSH (ssh_login_attempts-v2.csv), con el fin de modelar vectores de amenazas.

Metodología

          
Ciclo de vida de la ciencia de datos: ingesta local, validación de tipado abstracto, filtrado multivariable en estructuras complejas y programación funcional vectorizada en CPU de un solo bloque.
