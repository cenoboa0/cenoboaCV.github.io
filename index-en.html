CASE 05 — PRIVESC / LINUX

          
Privilege Escalation Chain on a Multi-Vulnerable Linux Machine

          
Security Researcher / Pentester — Master's in Cybersecurity, VIU

        

        
+

      

      

        

          
Scenario

          
Full penetration test against a Linux virtual machine designed with multiple independent vulnerabilities, aimed at identifying initial-access and privilege-escalation vectors that would allow total system compromise up to root access.

          
Achievements

          
Total system compromise by chaining six vectors: anonymous FTP access with exfiltration of an SSH private key; abuse of a NOPASSWD rule in sudoers over the Vim binary to obtain a root shell; code injection into a script periodically executed by a root cron job; retrieval of valid SSH credentials from a password file exposed on the web server; privilege escalation through misconfigured Polkit policies and exploitation of the PwnKit vulnerability (CVE-2021-4034); and remote code execution against the HTTP service with post-exploitation on the CuteNews CMS, including password hash cracking and access to the admin panel.

          
Methodology

          
Network reconnaissance and service enumeration (arp-scan, Nmap, Gobuster) → exploitation of unprivileged initial-access vectors → privilege escalation through misconfiguration abuse and known vulnerabilities → post-exploitation and persistence, with documented mitigation recommendations specific to each vector.

CASE 06 — R / WEB SCRAPING

          
Web Scraping, HTML Analysis, and Data Visualization in R

          
Data Researcher / Network Data Scientist — Master's in Cybersecurity, VIU

        

        
+

      

      

        

          
Scenario

          
Team exercise in scraping and data analysis on a public MediaWiki page, aimed at downloading its HTML, extracting and classifying all of its links, verifying their HTTP status, and building a visualization infographic from the results.

          
Achievements

          
Developed an R script that downloads and parses the target page's HTML, extracts the title and all links along with their text and URL, builds a frequency table, normalizes the URLs (absolute, relative, subdomains, anchors), and checks the HTTP status of each of the 162 links via HEAD() requests, detecting 157 successful responses (96.9%) and 5 timeout failures. Composed a final infographic with a histogram, a bar chart, and a pie chart.

          
Methodology

          
Download with httr::GET() → DOM tree parsing with XML::htmlParse() → link extraction via XPath expressions → URL normalization and classification → status verification with HEAD() and courtesy pauses between requests → visualization with ggplot2 and final composition of the three charts with gridExtra.

          

            R
            RStudio
            httr
            XML (XPath)
            ggplot2
            gridExtra
